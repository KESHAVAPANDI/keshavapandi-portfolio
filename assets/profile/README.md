# Profile Photo Asset Directory

Place your personal profile photo in this directory:

- File name: `profile-photo.jpg` or `profile-photo.png`
- Recommended aspect ratio: Portrait (~4:5 or 3:4, e.g., 600x750px or 800x1000px)

The portfolio About section will automatically display your image here when available. If the image file is not present, an elegant placeholder with your name is rendered.
